# Slide Deep Dive (HTML / PDF)

The full slide-by-slide deep explanation exists as a styled,
printable document:

- `prep/slide-deep-dive.html` - the source, styled for screen and print
- `prep/slide-deep-dive.pdf` - exported from the HTML via headless
  Chrome, 27 pages (cover + table of contents + one section per slide,
  18 slides)

Obsidian can't render either of these as a note directly. This page is
the vault-native pointer, plus an inline preview if your Obsidian build
supports HTML embeds.
