# Deck (HTML)

The presentable, clickable deck lives in `slides/index.html`, a
standalone HTML file with no external assets (works offline). Obsidian
can't render HTML as a note, so this page is the vault-native pointer
to it, plus an inline preview if your Obsidian build supports HTML
embeds.

**Open directly:** `slides/index.html` in a browser.
**Controls:** `→` / `←` navigate, `N` toggles speaker notes, `F` fullscreen.
